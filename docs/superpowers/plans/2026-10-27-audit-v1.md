# Audit pré-V1 — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prouver, tests versionnés à l'appui, que l'app ne perd jamais de données, tient ses promesses et éduque selon le niveau ; consigner les écarts dans `docs/audit-2026-11.md` et en lots.

**Architecture:** Quatre branches successives. Les tests de non-perte et de promesses s'appuient sur la racine de composition réelle (`Composition.surcharges`) avec une base drift en mémoire, un garde réseau `HttpOverrides` et des faux pour les services natifs (notifications, géoloc, fichiers). Les contrôles éducatifs sont des tests à cliquet. Les analyses (personnages, promesses, sécurité) produisent des sections du rapport.

**Tech Stack:** Flutter 3.47.7, drift (`NativeDatabase.memory()`), Riverpod (`ProviderScope.overrides`), `flutter_test`, `mocktail`, `integration_test` (SDK), `xvfb` en CI.

**Spec:** `docs/superpowers/specs/2026-10-27-audit-v1-design.md`

## Global Constraints

- Flutter **3.47.7** ; aucune dépendance ajoutée hors `integration_test` (dev, SDK).
- Branches : `chore/e2e-donnees`, `chore/tests-promesses-reseau`, `chore/controles-educatifs`, `docs/audit-2026-11`. Jamais de commit sur `main`. Conventional Commits, fin de message `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Avant chaque PR : `flutter analyze` 0 constat, `flutter test` vert (`TZ=Europe/Brussels`), puis `/code-review` ; `/security-review` en plus pour les branches 1 et 2.
- Code et commentaires en anglais, sans référence externe (ADR, docs, lot, date). Aucun texte UI en dur.
- **Test qui révèle un bug** : mergé avec `skip: '<description du défaut en anglais>'` ; le constat est noté (fichier:ligne, nom du test) dans `docs/audit-2026-11.md`. Le correctif n'est pas fait ici.
- **Fusion** : même clé primaire des deux côtés → la ligne au `updatedAt` (`dateModification` pour `parametres`) le plus récent gagne. `preferences` : la version locale est conservée en fusion *(choix agent)*. `meteo_cache` : hors périmètre de comparaison (cache) *(choix agent)*.
- **Opt-outs réseau** : appel déclenché par l'utilisateur permis ; appel automatique interdit quand l'opt-out est actif.
- **Hôtes autorisés** : `api.open-meteo.com`, `nominatim.openstreetmap.org`. Aucun autre.
- Contrôles éducatifs : cliquet (échec seulement sur régression).

## Review Focus

1. App tuée ou erreur au milieu d'un import → la base doit rester exactement dans l'état d'avant (transaction). → Task 4.
2. Fusion d'une sauvegarde contenant un élément supprimé localement depuis → l'élément réapparaît ; attendu : constat documenté (résurrection), pas de crash ni de doublon. → Task 3.
3. Sauvegarde volumineuse (≥ 5 000 tâches) → export/import aboutissent sans erreur en < 30 s en test. → Task 2.
4. Interface en anglais → chaque « pourquoi » a un texte non vide en `en` aussi. → Task 12.
5. Horloge de l'appareil décalée (`updatedAt` local dans le futur) → la fusion ne doit pas écraser la sauvegarde sans le signaler ; attendu : test documentant le comportement. → Task 3.
