# Tests

- `test/unit`, `test/widget`, `test/integration` reflètent l'arborescence de `lib/`.
- Doubles de test : `mocktail` uniquement.
- Enum ajouté ou modifié : couverture d'exhaustivité (libellés, glossaire D6) à étendre.
- Lancer d'abord les tests ciblés, la suite complète avant PR.
